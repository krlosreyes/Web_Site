01 · Fundamentos

Principios de Diseño

Cuatro pilares que guían cada decisión visual del sitio.

🔬
Autoridad Científica
El diseño debe transmitir rigor y credibilidad. Tipografía precisa, datos claros, sin ruido visual innecesario.
⚡
Claridad en Capas
Entrada fácil para principiantes, profundidad para avanzados. La jerarquía visual guía al usuario naturalmente.
🎯
Orientado a Acción
Cada sección tiene un objetivo concreto: leer, calcular, descubrir, descargar. Los CTAs son imposibles de ignorar.
📱
Mobile-First Real
No adaptado al móvil, sino pensado desde el móvil. Táctil, rápido, legible en condiciones reales de uso.

Advertencias / tips
Regla del 60-30-10: 60% fondos oscuros, 30% superficies y texto, 10% color de acento. El azul eléctrico se reserva para CTAs, links y elementos interactivos clave — usarlo con disciplina mantiene su impacto.

06 · Implementación

Resumen Técnico

Todo lo que necesitas para implementar este sistema en el stack actual (Astro + TailwindCSS + React).

🔤
Fuentes
Agregar a Layout.astro: Space Grotesk + Inter via Google Fonts. Sin dependencias adicionales.
🎨
Variables CSS
Definir el sistema de color como variables CSS en global.css. Tailwind consume las variables via @theme.
📦
Sin deps nuevas
Este sistema se implementa 100% con el stack existente. No requiere librerías de diseño externas como Shadcn o Radix.
🚀
Prioridad
Empezar por: variables de color + tipografía → Navbar → Hero → Cards de blog → Quiz → Footer.
