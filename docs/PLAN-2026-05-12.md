## ⚠️ Si algo se rompe

- **Build falla con Tailwind v4:** revisar primero si la utility class
  usada existe (ej. `text-accent` requiere `--color-accent` en `@theme`).
  Si dudás, reemplazar por valor arbitrario `text-[#00C49A]`.
- **Componente se ve en blanco:** suele ser por una clase con typo en
  el nombre del token. Inspeccionar con DevTools.
- **Hostinger no actualiza:** revisar que el commit llegó a `main` con
  `git log origin/main -1`. Hostinger redeploya en 90-120s.
- **Rollback rápido:** `git revert HEAD && git push` deja el sitio en
  estado funcional inmediato; debug del fix con calma después.
